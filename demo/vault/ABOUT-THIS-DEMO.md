# Demo vault (fictional)

Everything in this folder is made up: **Sam Rivera** and **Jordan** are fictional people. It exists so you can try the system, or film it, without showing a real vault.

What's in it: a profile and goals for Sam, three daily notes (the last one, 2026-11-05, is still untriaged), one phone capture in `00 Inbox`, two ideas, one project, a friend, an agent-written draft and yesterday's brief.

Build a working copy (the pack's system files + this sample content, with a short git history):
```bash
bash demo/build-demo-vault.sh ~/second-brain-demo
```
Then open `~/second-brain-demo` in Obsidian, connect Notion to a **separate demo workspace** (see `demo/NOTION-DEMO-SETUP.md`) and run `claude` → `/brain` in that folder.
