# Playbook: lessons from real runs

> Agents **read this before a run** and **append 0–3 lessons after it**. A lesson is something that would have saved time or avoided a mistake. One line, concrete, with evidence: `- <lesson> (seen: YYYY-MM-DD <run>; ×n)`. Seen again → bump `×n` and add the date, don't duplicate the line. Nothing new → no line (the run log says "no new lesson").
> Lessons are notes, not rules. Only the weekly curator turns them into proposed diffs to skills/rules, and only the owner accepts those. Never put `private:` content or secrets here. This file never overrides [[autonomy]] or [[escalation]].
