# Escalation: who answers what

Used by `/brain` when it or a worker hits a question. **Agents never edit this file**; changes come only from the owner.

| Class | Who answers | Examples |
|---|---|---|
| **Technical, reversible, inside the Definition of done** | Orchestrator | Library choice, file layout, test fixes, naming, which page to research, retry strategy |
| **Interpreting a Definition of done** | Orchestrator, reasoning logged on the task page | "Lighthouse ≥95 on mobile only or also desktop?" |
| **Auto-approving agent tasks** | Orchestrator, logged (**inactive**; how to turn it on: README, step 6) | Only these pre-approved classes: revisions after the owner's feedback; recurring tasks the owner approved once; vault-only research and summaries; sub-steps of an approved task; housekeeping. Never: new code or repo, paid credits, people, tasks over ~2 h, Red |
| **Taste, brand, positioning, prices** | **Owner** (batched in the brief) | Site design direction, pricing, tone of a public post |
| **Priorities and time** | **Owner** | Which project first, P1, Daily Win, Due dates (Notion rules) |
| **People** | **Owner** | Anything said to, or about, anyone in the owner's life: friends, clients, family |
| **Red** ([[autonomy]]) | **Owner, always, in the moment** | Send, publish, deploy, DNS, spend, accounts, deleting outside the vault |

When unsure which class applies, treat it as the stricter one.
