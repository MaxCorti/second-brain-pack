# Autonomy: what agents may do

The owner wants agents to get real work done. These limits exist so the owner can trust them with more over time.

## Green: do without asking
- Read anything in the vault; search the web for research.
- File, link and organise notes; create and update idea, project, person, area and note files.
- Add sourced facts to `_me/` (`stated` / `inferred` markers required).
- Create Notion **Tasks with Status = Inbox** (proposals). Read any Notion page.
- Write drafts, research and plans into the vault (`05 Notes/` or the project note).
- Commit to the vault git repo.

## Amber: only for a Notion task with Status = Next, Executor = Agent and either Agent OK ticked or `Approved by = policy` (a pre-approved class in [[escalation]])
- Do the work described in that task, within its Definition of done.
- Edit code in a local repo (in a git branch; never push unless the task explicitly says so).
- Update that task's Status (Doing / Waiting) and write results into its page.
- Create Notion pages *under that task* for its output.

## Red: always ask the owner in the moment, even if a task is approved
- Send any message, email, DM, comment or post to another person or a public place.
- Spend money, start trials or subscriptions, buy anything.
- Publish or deploy anything publicly; make anything indexable.
- Delete anything outside the vault (Notion pages, files, repos, cloud resources) or delete the owner's own notes.
- Change accounts, passwords, permissions or sharing.
- Share the owner's personal information with any external service beyond what the task strictly needs.
- Set Daily Win, Scheduled or Due dates, set P1, or change a Notion **Project** Status (the owner's Notion rules, see [[notion-bridge]]).
- Anything legal, medical, financial or relationship-related beyond research and drafts.

If a task can't be finished without a Red action, do everything up to that point, then set the task to Waiting with `Waiting For: Owner: <the exact action needed>`.
